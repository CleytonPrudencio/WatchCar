
# 🚔 WatchCar
WatchCar é um sistema web em desenvolvimento com o objetivo de registrar e acompanhar furtos e roubos de veículos automotivos, ajudando a mapear regiões mais perigosas para motoristas e autoridades.

## 🧭 Objetivo
Facilitar o monitoramento de áreas com alto índice de criminalidade veicular. Usuários podem cadastrar ocorrências e visualizar estatísticas em tempo real, ajudando a evitar áreas de risco.

## 👥 Público-alvo
Destinado ao público geral, com foco especial em motoristas de aplicativo, transportes e profissionais que passam por diferentes regiões da cidade com frequência.

## 🔍 Funcionalidades principais
- Registro de furtos e roubos de veículos.
- Mapa interativo com marcações de ocorrências.
- Gráficos com estatísticas de perigosidade por região.
- Cadastro de autoridades como policiais, investigadores e delegados.
- Sistema de apoio à patrulha e monitoramento inteligente.

## 🛠️ Tecnologias utilizadas
- Backend: Spring Boot
- Frontend: Vue.js
- Banco de dados: Relacional (ex: MySQL ou PostgreSQL)

### API externa: 
- ViaCEP para integração de endereços
